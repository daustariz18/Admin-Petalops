Petalops Admin

PETALOPS

Plataforma SaaS para floristerias

Guia operativa para usuarios de tienda que gestionan catalogo de productos: login, listado, filtros, edicion y creacion por fotos.

Version del manual: 2.0
Fecha: 2 de abril de 2026
Destinatario: Dueños y administradores de floristerias

Codigo de documento MAN-ADM-PETALOPS-002
Elaborado por Equipo de Implementacion Petalops
Clasificacion Uso operativo cliente

1. Objetivo del sistema

Petalops Admin permite entrar a la tienda, visualizar productos existentes, filtrar, editar, activar o desactivar productos, eliminarlos y crear productos nuevos a partir de fotos en un flujo guiado.

2. Requisitos previos

  • Tener usuario activo y contraseña valida.
  • Contar con internet estable.
  • Usar navegador actualizado (Chrome, Edge o equivalente).
  • Usar imagenes JPEG, PNG o WebP, maximo 5 MB por archivo.

3. Vista de inicio de sesion

3.1 Proposito

Permitir acceso seguro a la tienda correspondiente sin exponer datos tecnicos al usuario.

3.2 Pasos

  1. Ingrese su correo.
  2. Ingrese su contraseña.
  3. Pulse Ingresar.
El sistema identifica la tienda desde el dominio del correo y, al autenticar correctamente, redirige a la gestion de productos.

4. Vista principal: Mis productos

4.1 Elementos de la pantalla

  • Marca Petalops + logo de la tienda activa (por ejemplo Flora).
  • Titulo Mis productos y contador de productos/categorias.
  • Boton + Nuevo producto.
  • Boton Salir.
  • Tarjetas de resumen: Total, Activos, Inactivos, Producto mas caro.

4.2 Filtros y busqueda

  • Busqueda por nombre.
  • Filtro por estado: Todos, Activo, Inactivo.
  • Filtro por categoria.
  • Filtro por rango de precio.

4.3 Acciones por producto

  • Editar: abre modal para cambiar nombre, precio y categoria.
  • Eliminar: abre modal de confirmacion.
  • Switch Activo/Inactivo: cambia el estado del producto.

4.4 Feedback visual

Se muestran notificaciones tipo toast para confirmar acciones exitosas o reportar errores.

5. Vista de nuevo producto (flujo por fotos)

5.1 Header limpio

  • Boton Volver.
  • Titulo Nuevo producto.

5.2 Flujo recomendado

  1. Suba fotos en la zona grande de arrastrar y soltar.
  2. Revise la vista previa generada automaticamente.
  3. Complete/edite nombre, precio y categoria en cada card.
  4. Pulse Guardar productos.

5.3 Zona de carga

  • Texto visible: Arrastra tus fotos o haz clic para subir.
  • Muestra limite total y cupos disponibles.

5.4 Estado vacio

Si no hay fotos, se muestra un mensaje simple indicando que primero debe subir imagenes.

5.5 Footer sticky

  • Boton Nueva categoria.
  • Boton Guardar productos.
  • Guardar se habilita cuando hay productos listos y datos minimos completos.

6. Edicion y eliminacion

6.1 Modal de edicion

  • Campos: Nombre, Precio, Categoria.
  • Valida datos obligatorios antes de guardar.

6.2 Modal de eliminacion

  • Solicita confirmacion explicita.
  • Una vez confirmado, elimina el producto de la lista.

7. Cierre de sesion

  1. Pulse Salir desde la vista de gestion de productos.
  2. El sistema limpia sesion y vuelve a login.

8. Mensajes de error y acciones recomendadas

Situacion Accion recomendada
Correo invalido o contraseña incorrecta. Verifique credenciales e intente nuevamente.
No hay categorias para guardar productos. Cree una categoria antes de guardar.
Precio invalido o vacio. Ingrese un valor mayor a 0.
Fallo de red/API. Revise conexion y repita la accion.
CORS o error de backend. Contacte soporte tecnico con el mensaje mostrado.

9. Soporte

Para soporte, comparta siempre:

  • Fecha y hora del incidente.
  • Correo del usuario afectado.
  • Paso exacto donde ocurrio (login, filtros, editar, crear, guardar).
  • Mensaje de error visible en pantalla.
