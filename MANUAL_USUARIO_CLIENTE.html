1. Objetivo del sistema

Admin PetalOps permite a usuarios autenticados crear productos y asociarles una imagen. El flujo está diseñado para registrar el producto, subir la imagen y confirmar la vinculación en un proceso único, guiado por pasos de progreso.

2. Requisitos previos

  • Tener usuario y contraseña activos en la plataforma.
  • Contar con conexión a internet estable.
  • Usar un navegador actualizado (Chrome, Edge o equivalente).
  • Tener imágenes en formato JPEG, PNG o WebP.
  • Tamaño máximo de imagen permitido: 5 MB.

3. Inicio de sesión

  1. Ingrese al módulo de administración.
  2. Complete el campo Email.
  3. Complete el campo Contraseña.
  4. Presione Entrar.
Si las credenciales son válidas, el sistema redirige automáticamente al dashboard del tenant y habilita el formulario de Nuevo producto.

4. Pantalla Nuevo producto

La pantalla principal contiene:

  • Campo Nombre del producto.
  • Campo Precio.
  • Selector de Categoría.
  • Selector de archivo de imagen.
  • Vista previa de la imagen seleccionada.
  • Botón Crear producto.
  • Botón Cerrar sesión (parte superior).

5. Crear una nueva categoría

  1. Abra el selector de Categoría.
  2. Seleccione + Agregar nueva...
  3. Se abrirá el formulario/modal Nueva categoría.
  4. Escriba el nombre de la categoría.
  5. Presione Guardar.

Al guardar correctamente, la categoría se agrega a la lista y queda seleccionada en el formulario del producto.

Si desea cancelar, presione Cancelar y el formulario de nueva categoría se ocultará sin guardar cambios.

6. Crear producto con imagen

  1. Escriba el nombre del producto.
  2. Ingrese el precio (debe ser mayor a 0).
  3. Seleccione una categoría existente o cree una nueva.
  4. Adjunte la imagen del producto.
  5. Presione Crear producto.

Durante el proceso, verá una barra de avance con estas etapas:

Etapa Descripción
Registrar Se crea el producto en la base de datos.
Subir La imagen se carga a almacenamiento S3 con URL firmada.
Confirmar Se confirma en backend la imagen asociada al producto.
Listo El proceso finaliza correctamente.

7. Resultado exitoso

Cuando la operación termina correctamente, se muestra:

  • ID del producto.
  • Clave S3 de la imagen.
  • URL pública o de acceso de la imagen.
  • Botón Crear otro producto para iniciar un nuevo registro.

8. Mensajes de error y acciones recomendadas

Situación Acción recomendada
Debe seleccionar una imagen. Adjunte un archivo antes de continuar.
Precio inválido (menor o igual a 0). Ingrese un valor numérico mayor a 0.
No se seleccionó categoría. Seleccione una categoría existente o cree una nueva.
Formato de imagen no permitido. Use únicamente JPEG, PNG o WebP.
Imagen supera 5 MB. Optimice la imagen y vuelva a intentarlo.
Fallo en confirmación final. Use el botón Reintentar confirmación.
Sesión expirada (401). Inicie sesión nuevamente.

9. Cierre de sesión

  1. Presione Cerrar sesión en la parte superior de la pantalla.
  2. El sistema limpiará la sesión y lo llevará a la vista de login.

10. Soporte

Para incidentes de acceso, validación de datos o carga de imágenes, contacte al equipo de soporte técnico del proyecto e incluya:

  • Fecha y hora del incidente.
  • Correo del usuario afectado.
  • Mensaje de error visible en pantalla.
  • Paso exacto donde ocurrió la falla (Registrar, Subir o Confirmar).
